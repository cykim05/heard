## Lessons worth remembering

- **Pre-commit can't see commit messages.** Git hands the message
  to commit-msg, not pre-commit — reading `.git/COMMIT_EDITMSG`
  in pre-commit gets a stale value. Split the hook early.
  (Day 1 incident.)
- **Default argument lists in rotation helpers silently drop
  renamed entries.** Auto-discover by transport tag instead of
  a hardcoded include list — caught after 18 days of utterances
  went to Haiku alone (Day 1).
- **Gemini Flash caps output at ~16 K tokens**, regardless of its
  1 M input context. Chunk outputs whenever Korean/Japanese
  translation exceeds a few K tokens.
- **LLM raters are conservative on isolated questions.** Giving
  them persona context when scoring clarity would lift Gate 4's
  acceptance rate closer to human acceptance.

## What I'd do differently

- Set up per-phase API spend caps inside `budget.json` from the
  start, not after the fact. The three killed Track B runs cost
  ~USD 0.4 before we rewrote the strategy.
- Run the full SUT sweep early on Day 2 afternoon, not Day 3 —
  the 80-minute wall time is awkwardly long to squeeze between
  other work.
- Treat HF upload as a Day 3 stretch goal; it wasn't blocking and
  took ~2 minutes.
